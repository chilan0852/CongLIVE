# Brand & launch copy

## Core tagline

- 中文：**打开就播，所见即现场。**
- English: **Open it. Go live. Be there.**

## One-liner

- 中文：葱直播是一个基于 WebRTC 的开源直播系统：Android 和浏览器都能开播，WHEP 低延迟观看，支持封面、弹幕、录像、插件和 Live2D 加载器。
- English: CongLive is an open-source WebRTC live-streaming platform: publish from Android or the browser, watch over WHEP with low latency, and manage covers, chat, recordings, plugins and a Live2D loader.

## Poster lines

- 手机是摄像机，网页是直播间。 / Your phone is the camera. The web is the room.
- 互动，不该等加载。 / Interaction should never wait for a loading spinner.

## GitHub About

An open-source WebRTC live-streaming platform: Android/browser WHIP publishing, WHEP playback, covers, chat, DVR recording, plugins and a Live2D loader.

## Notes

- 不承诺“零延迟”；使用“低延迟 / 几乎同步”。
- 宣传片不展示 Live2D 模型；模型需用户自备并遵守授权。
- 公开发布请遵守当地直播、隐私、版权与备案要求。
