## 已检查

- 仓库自有代码：MIT；无第三方模型、无 Cubism Core、无密钥、无证书、无 APK/录像。
- 宣传片：无 Live2D 模型形象、无二维码/域名、无第三方音乐；音效由 `make_audio.py` 合成；截图仅含本项目 UI。
- 服务端：`server/private-model` 的公开静态路径已从 Compose/Nginx 移除；模型文件本身保留在服务器磁盘，但不再通过 Web 提供下载。需要自测时请使用有访问控制的私有地址，或仅在本地加载。
- 第三方依赖：见 `THIRD_PARTY_NOTICES.md`；Live2D Core 仅在运行时从官方 CDN 加载。

## 仍需运营者自行处理

1. 公开直播/点播的 ICP、公安备案、实名、未成年人保护、内容审核、必要的文化/视听许可。
2. 摄像头、屏幕、麦克风拍摄的参与者同意、隐私告知、录像留存与删除。
3. 音乐、影视、游戏、模型、字体、封面和弹幕的版权/授权。
4. 管理员密码、HTTPS、后台访问控制、备份和日志留存。
5. 侵权投诉与下架渠道。

## 残余风险

- 公网 SRS/API/管理后台仍可能被扫描；项目不含 WAF/限流/风控。
- 私有模型文件仍保存在服务器磁盘，只是不再通过 Web 提供；建议加密或移出部署目录。
- 内容审核、实名、未成年人保护、版权与录制同意必须由运营者补齐。
- 第三方许可证的实际版本以各上游为准，发布前应生成 SBOM/依赖清单复核。
